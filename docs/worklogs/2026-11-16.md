## 실기기 피드백 1: 빈 판·튜토리얼 승패(결정 021)
- 실기기에서 튜토리얼 중·후, 백그라운드 복귀 후에 판이 비어 보이고 「처음부터」를 눌러야 나옴 → 켜질 때 판 영역 크기가 0으로 잡힌 채 그려졌다고 판단. 판 영역 크기 감시(ResizeObserver)·창 크기·화면 복귀(visibilitychange·pageshow) 때 다시 그리도록 수정, 크기가 너무 작을 때는 그리지 않음. 시뮬레이터에서는 처음부터 정상이라 재현은 못 함.
- 튜토리얼에 패배(무행동 → 양을 물림) → 같은 판 다시 → 승리(강으로 밀기, 별 3개 조건) 장면 추가. 늑대 차례에는 덮개를 걷음, 말풍선은 판 아래.
- 확인: Playwright(시스템 Chrome)로 16단계 자동 진행·완료 저장, iOS 시뮬레이터에서 패배·승리 장면 화면 확인. 시뮬레이터에서 연달아 빠르게 누르면 단계가 바뀌기 전 입력이 덮개에 막힐 수 있음(사람 속도에서는 문제 없음).
