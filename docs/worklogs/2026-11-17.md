## 만든 것
- `src/main.ts`: 섬·구름·조명·그림자·위아래 흐림(틸트시프트), 화면 어디든 누른 자리가 조이스틱, 자동 돌팔매, 회전 칼날, 보석·자석, 레벨업 3택, 쓸어내기(멈칫·흔들림·진동·충격파 고리), 2분 타이머, 결과 화면, 한영.
- `src/game/rules.ts` + 테스트 3개(적 증가 단조성, 3택 중복·회복 조건, 충전량 양수).
- 개발 훅 `__demo`: `stats()`, `stress(300)`, `charge()`, `sweep()`, `step(초, x, z)`(화면이 가려져도 규칙 진행), `bench(n)`.
- 고친 것: 적 300마리가 몰리면 서로 밀다가 가장자리에서 저절로 떨어지던 문제 → 맞아서 밀린 적만 떨어지게.
