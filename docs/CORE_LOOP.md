# 한 방의 흐름과 핵심 손맛 (초안, 결정 014)

GDD의 1장이 될 문서입니다. 수치는 프로토타입에서 다시 정합니다. **이 문서의 시간 수치는 설계용이며 홍보 문구에 쓰지 않습니다.**

## 1. 한 의뢰의 흐름

| 단계 | 화면에서 일어나는 일 | 의도 |
|---|---|---|
| ① 도착 | 어둑하고 먼지 낀 미니어처 방이 비스듬한 각도로 보입니다. 손님 쪽지 한 줄("할아버지 시계방, 다시 열고 싶어요") | 첫 1초에 "엉망"을 보여 줌(숏폼 시작 장면) |
| ② 둘러보기 | 한 손가락으로 방을 좌우로 살짝 돌리고(±30°), 두 손가락으로 확대합니다. 고칠 곳은 은은하게 반짝입니다 | 무엇을 할지 글 설명 없이 보이게 |
| ③ 작업 | 물건 하나를 눌러 가까이 보고, 그 물건에 맞는 동작을 합니다(2장). 물건마다 따로 끝나고 바로 저장됩니다 | **한 정거장 사이에 물건 하나**를 끝낼 수 있는 단위. 언제 끊어도 손해 없음 |
| ④ 방이 살아남 | 고친 물건이 늘수록 방이 밝아지고, 소리(시계 초침, 주전자)가 하나씩 돌아옵니다 | 진행 막대 대신 방 자체가 진행도 |
| ⑤ 마무리 | 마지막 물건을 끝내면 조명이 켜지고 창문이 열립니다. **전후 비교 슬라이더** → 공유 카드 | 숏폼 끝 장면, 공유 동기 |
| ⑥ 이야기 한 조각 | 손님의 짧은 답장 한 줄과 복원한 물건 하나가 "내 거리" 진열장에 들어갑니다 | 다음에 다시 올 이유(이야기·수집) |

- 실패와 시간 제한은 없습니다. 잘했다는 표시는 "손님 요청 달성"(예: 창가 먼저, 깨진 것 먼저) 정도로 가볍게 둡니다.
- 의뢰 하나의 목표 분량: 물건 8~15개. 일반 의뢰는 짧게, 주말 의뢰는 크게.

## 2. 핵심 동작 (손맛)

동작 수는 적게, 대신 각 동작의 손맛(소리·햅틱·빛)을 깊게 다듬습니다(결정 009).

| 동작 | 손가락 | 손맛 | v1 프로토타입 |
|---|---|---|---|
| **닦기** | 문지르기 | 문지른 자리만 먼지가 지워지고, 문지르는 속도에 따라 소리 높이가 바뀜. 다 닦이면 반짝 + 짧은 진동 | ✅ |
| **제자리 놓기** | 끌어 놓기 | 맞는 자리 근처에서 자석처럼 "딸깍". 자리에는 흐린 실루엣 힌트 | ✅ |
| **붙이기** | 조각을 돌려 맞추기 | 깨진 접시·액자 조각 2~4개. 맞으면 이음매가 금빛으로 빛나며 붙음 | ✅ |
| 칠하기 | 문지르며 색 입히기 | 빛바랜 물건에 원래 색이 번져 돌아옴(닦기의 변형) | 이후 |
| 조이기 | 원 그리기 | 헐거운 나사·태엽을 돌림. 끝에 "딸깍" 멈춤 | 이후 |

## 3. 고장 유형 첫 목록 (동작에 묶음)

고장 유형은 **동작 + 겉모습 + 도구**의 조합인 데이터입니다. 새 고장 유형은 대부분 기존 동작의 변형이라 AI가 데이터로 추가할 수 있습니다(결정 012).

| 고장 유형 | 동작 | 도구 | 겉모습 |
|---|---|---|---|
| 먼지 | 닦기 | 천 | 회색 먼지 막 |
| 얼룩 | 닦기(여러 번) | 스펀지 | 진한 얼룩, 문지를수록 옅어짐 |
| 녹 | 닦기(세게) | 솔 | 갈색 녹, 긁는 소리 |
| 빛바램 | 칠하기 | 붓 | 채도가 빠진 물건 |
| 제자리 아님 | 제자리 놓기 | 손 | 바닥·엉뚱한 선반에 놓인 물건 |
| 넘어짐 | 제자리 놓기(돌려 세우기) | 손 | 쓰러진 물건 |
| 깨짐 | 붙이기 | 풀 | 조각난 물건 |
| 꺼진 전구 | 제자리 놓기(교체) | 새 전구 | 어두운 전등 |

## 4. 첫 방 틀 3개 (테마 후보)

나라와 나이를 가리지 않고 알아볼 수 있는 공간으로 고릅니다.

1. **오래된 시계방**: 태엽·유리·작은 부품 → 붙이기·조이기가 어울림
2. **할머니 부엌**: 그릇·찬장·주전자 → 닦기·제자리 놓기 중심, 따뜻한 소리
3. **동네 문방구**: 진열대·연필통·쏟아진 구슬 → 제자리 놓기 중심, 색이 많아 전후 대비가 큼

## 5. 첫 30초 (설명 없는 시작)

설치 후 첫 화면은 메뉴가 아니라 **먼지 낀 액자 하나**입니다. "문질러 보세요" 한 줄만 띄우고, 닦으면 오래된 사진이 드러나며 그 사진 속 방이 첫 의뢰가 됩니다.

## 6. 자주 올 이유

- **오늘의 의뢰**: 하루 하나, 모두 같은 시드라 같은 방·같은 엉망(결정 011). 공유 카드에 오늘 날짜가 찍힘
- **자유 의뢰**: 이미 연 방 틀로 시드를 바꿔 무한히(광고로 막지 않음)
- **내 거리**: 복원한 방마다 거리의 가게 하나에 불이 켜지고, 복원한 물건이 진열장에 쌓임
